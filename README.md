# Prince Portfolio — Commentaires

Ce dépôt public héberge **uniquement** les discussions servant de commentaires
au blog de princekouame.com.

## Fonctionnement

- Les commentaires sont propulsés par [giscus](https://giscus.app/fr), adossé à GitHub Discussions.
- Une discussion est créée automatiquement par le bot `giscus` au tout premier
  commentaire de chaque article.
- Les visiteurs commentent avec leur compte GitHub, directement depuis le site.
- Le mapping article ↔ discussion se fait par l'identifiant technique de
  l'article, afin que les versions française et anglaise d'un même article
  partagent le **même fil de discussion**.

## Ce que ce dépôt ne contient pas

- Aucun code du portfolio (il est privé).
- Aucune base de données, aucune donnée personnelle.
